# DroneRF DIY · Radio

`dronerfdiy.com/redio/` 的业余无线电 A / B / C 类操作技术能力学习前端。

本项目以 Google AI Studio 生成项目为 UI / 交互基线，但题库数据层不再使用示例摘录：**题目必须来自对应类别的原始题库，并通过完整性校验后才能启用题库、模拟考试和知识图谱。**

## A / B / C 学习入口

- **A 类**：当前原始题库已完整导入，683 / 683 道；可使用完整题库浏览、模拟考试、错题本、结构化考点和全景知识图谱。
- **B 类**：已建立独立学习入口；当前尚未提供 B 类原始题库，因此不复用 A 类题目，也不自动生成题目。
- **C 类**：已建立独立学习入口；当前尚未提供 C 类原始题库，因此不复用 A 类题目，也不自动生成题目。

导入 B / C 原始题库后，按与 A 类相同的数据完整性规则启用对应学习功能。

- 操作能力频率范围：30–3000 MHz
- 最大发射功率：≤25 W
- 7 / 14 / 21 / 28 MHz 等低于 30 MHz，不属于 A 类发射能力范围
- 当前考试结构：40 题（32 单选 + 8 多选），答对 30 题合格，40 分钟
- 电台执照继续使用：有效期届满 30 个工作日前申请更换
- 应急临时设台：按规定在 48 小时内报告

以上口径在本项目中以当前提供的 A 类题库内容为依据。

## 本地运行

```bash
bun install
bun run dev
```

## 检查与构建

```bash
bun run scripts/verify-a-bank.ts
bun run lint
bun run build
```

Vite 配置：

- `base: /redio/`
- 输出目录：`dist/redio/`

Cloudflare Worker Static Assets 从仓库根目录的 `dist/` 发布，因此最终路径为：

```text
dist/redio/index.html -> https://dronerfdiy.com/redio/
```

Cloudflare Git Build 推荐：

```text
Build command:  bun run build
Deploy command: npx wrangler deploy
Root directory: /
Production branch: main
```

当前生产应用不调用 Gemini API，也不需要 `GEMINI_API_KEY`。
